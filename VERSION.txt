HAPPY TRAILS — site assets, version 1.0

The folder carries the version; the files inside do not. Every page and asset
has a plain name so that links never need rewriting and replacing a file is
simply replacing a file.

WHAT IS HERE
  index.html            the main map
  trails.html           the list of trails
  about.html
  contact.html
  beltline.html         the finished trail page
  <nine more>.html      one per route on the main map, all placeholder content
  trail-engine.js       how a trail page works — shared by all ten
  happy-trails.css      every colour, size and font — shared by all fourteen
  maps/                 the map drawings, one per trail, for editing
  media/                pictures and video, one folder per trail
  social/               the 1200x630 link previews
  legend/               the legend icons
  favicon.*

BEFORE IT GOES LIVE
  1. media/beltline/ is EMPTY of pictures — run download.ps1 inside it once to
     fetch them from the CDN. Until then the Beltline shows placeholders.
  2. The nine placeholder trails have drawn maps and invented text. Replace as
     each one is written.
  3. Social previews use absolute URLs built from BASE in make_meta.py. If the
     site's address is not huzzahdesign.com/happy-trails/, change it there and
     re-run, or the link previews will come out blank.
